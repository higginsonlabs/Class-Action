# Class Action

A consumer application that simplifies participation in class-action lawsuits:
checking eligibility, joining eligible claims, and managing the process in one place.

## How it works
1. Determine eligibility for major class-action claims
2. Join eligible claims
3. Manage the process through the application

## Status
Currently in development.
